# ============ ЭТАП 3: ДЕМО-ДАННЫЕ ============

## Как загрузить демо-данные факультета ВГУ

### Шаг 1: Убедиться, что проект инициализирован

```powershell
cd D:\TutorSys
.venv\Scripts\Activate.ps1

# Миграции должны быть применены
python manage.py migrate
```

### Шаг 2: Запустить Django shell

```powershell
python manage.py shell
```

### Шаг 3: Загрузить демо-данные

Внутри shell:
```python
from core.seed import run
run()
```

Вы увидите:
```
✓ База очищена

📚 Создаю специальности...
  ✓ 6-05-0533-11 — ПИ
  ✓ 6-05-0533-09 — ПМ

🏛️  Создаю кафедры...
  ✓ Кафедра математики
  ✓ Кафедра информационных технологий и управления бизнесом
  ✓ Кафедра прикладного и системного программирования

👥 Создаю студенческие группы...
  ✓ 26ПИ1д (15 студентов)
  ✓ 26ПИ2д (15 студентов)
  ✓ 26ПМ1д (24 студента)

...

✅ ВСЕ ДЕМО-ДАННЫЕ ЗАГРУЖЕНЫ
```

### Шаг 4: Выход из shell

```python
exit()
```

### Шаг 5: Запустить сервер

```powershell
python manage.py runserver
```

## 🔄 Как очистить демо-данные?

from core.seed import run
run()

## 💡 Сценарий демонстрации

### 1️⃣ Вход как deputy_dean (Зам. декана)

```

Пароль: pass123
```

Откройте: http://127.0.0.1:8000/settings/

Что показать:
