Импорт учебных данных из Excel

Загрузите файл .xlsx с кафедральной нагрузкой. Система сама прочитает файл и создаст или обновит данные для работы приложения — вручную заполнять базу данных не нужно. Существующие записи не удаляются; повторная загрузка обновляет совпадающие данные.

В исходной таблице нет названия кафедры и года набора. Укажите кафедру, которой принадлежат импортируемые дисциплины, и год начала учебного года для первого курса. Если числа групп достаточно, специальности в одной строке будут разделены на группы; при одной общей группе коды сохраняются как совместная специальность.

Поддерживаемые поля таблицы

Название дисциплины, код специальности, курс, семестр, форма обучения, число студентов и групп, подгруппы, плановые часы лекций, практик и лабораторных, число контрольных работ, УСР, экзамен и зачёт.
