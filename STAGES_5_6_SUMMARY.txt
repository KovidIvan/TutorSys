Логиниться как **head** (pass123):

```
Логин: head
Пароль: pass123
```

1. **Откройте** http://127.0.0.1:8000/distribution/

**Что видно:**
- 📚 **Левая колонка**: Таблица элементов нагрузки (лекции, практики, лабораторные, экзамены, зачёты)
  - Колонки: Дисциплина | Вид | Группа | Часы | Преподаватель
  - Выпадающие списки с преподавателями в последней колонке

  - Карточка на преподавателя:
	- ФИО, должность, ставка
	- **Большое число** — итого часов преподавателя (обновляется после назначения!)
	- Зелёный/жёлтый/красный бэйдж статуса
	- Список предупреждений (если статус не OK)

**Сценарий тестирования:**

2. **Выберите элемент нагрузки** (например, лекции по программированию)
   - В выпадающем списке выберите преподавателя (например, "Павлыш Э.В.")
   - **HTMX отправляет POST без перезагрузки страницы**

3. **Смотрите панель справа:**
   - Число часов для этого преподавателя **должно измениться**
   - Если часов становится > максимума — цвет **красный**
   - Если 80–100% — жёлтый, иначе зелёный

4. **Результат:** ✅ HTMX работает, панель обновляется без перезагрузки

```
Логин: teacher
Пароль: pass123
```

1. **Откройте** http://127.0.0.1:8000/journal/

**Что видно:**

  - Если записей нет — "Записей пока нет"
  - Если есть — строки с колонками: Дата | Время | Дисциплина | Вид | Часы | Тема

- ➕ **Правая колонка**: Форма добавления записи
  - "Дисциплина и вид работы" — выпадающий список (all LoadItem для этого преподавателя)
  - "Дата" — date input (требуется)
  - "Время" — time input (опционально)
  - "Часы" — number input, step=0.5

  - кнопка "Добавить запись"

**Сценарий тестирования:**

2. **Заполните форму:**
   - Выберите дисциплину из выпадающего списка (должны быть те, что назначены этому преподавателю)

   - Впишите часы (например, 2.0)
   - Тема: "Введение в программирование"

3. **Нажмите "Добавить запись"**
   - Запись должна появиться в таблице слева
   - Страница перезагружается (обновляется)

4. **Результат:** ✅ Запись добавлена и видна в журнале

## ⚠️ Важные моменты

### Если элементов нагрузки нет

**Причина:** LoadItem не были созданы. Нужно пересчитать нагрузку.

**Решение:**
1. Логиниться как deputy_dean
2. Откройте /settings/
3. Нажмите "🔄 Пересчитать нагрузку всех кафедр"
4. Вернитесь на /distribution/ — элементы должны появиться

### Если выпадающие списки пусты

**Причина:** Нет преподавателей в кафедре head'а

**Решение:** В админке проверьте, что преподаватели привязаны к кафедре head'а (department).

### Если HTMX не работает (при выборе преподавателя панель не обновляется)

**Причина:** Локальный файл HTMX не загружается или запрос отклонён сервером.

**Решение:** Проверьте, что `base.html` подключает `core/vendor/htmx.min.js`, а в браузере запрос `/static/core/vendor/htmx.min.js` возвращает HTTP 200.
